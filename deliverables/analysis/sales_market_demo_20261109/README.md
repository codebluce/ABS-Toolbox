# 销售机构分市场Demo

独立预览，未替换或发布正式机构统计面板。原管理人、托管行表保留，原销售机构表的位置换成两张绿色表头卡片；桌面并排、手机上下排列。

源：1106定稿台账。交易所合并上交所、深交所：94个项目、912.11亿元、19家券商；银行间：42个项目、416亿元、20家银行及券商。交易所沿用原券商筛选；银行间不剔除银行销售机构。各市场规模占比用该市场总项目规模作分母，联席项目按各参与机构重复归属。

用户确认建行与建设银行为同一家，Demo统一为建设银行。归并发生在项目销售机构展开前，同一项目同时出现两种名称只计一次；投行认购别名同步归并。原始台账不改名。

投行认购规模按项目所属市场拆分，沿用原中标份额口径。银行普通认购不并入投行认购列。只有认购、没有该市场销售角色的机构不额外新增销售行；这部分记录于数据文件的ibWithoutSalesRole。因此拆表后的投行认购合计不保证等于旧表把所有市场认购都配给机构后的合计。

保留原始销售机构名称，沿用既有批准的名称归并，不新增别名。中保登、非标不放入这两张销售表，具体排除项目数和规模保存在data.json。券商子集的项目数、参与规模合并后与原两个市场统计一致；桌面及手机已检查显示、滚动及机构行数。

生成脚本：scripts/lab/build_sales_market_demo.py。index.html、data.json、截图及validation.json为可回查成果。
