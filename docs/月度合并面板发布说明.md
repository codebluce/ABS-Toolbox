# 月度合并面板正式生成

生成器新增 `--monthly-bookkeeping-release`，自动启用月度面板，使用 `preview=False` 和正式标签。可以单独传入，也可同时传入 `--monthly-bookkeeping`；同时传入 `--bookkeeping-demo` 时正式标签优先。

```sh
.venv/bin/python scripts/gen_integrated_dashboard.py <定稿台账.xlsx> <已有本地HTML路径> --monthly-bookkeeping-release
```

省略输出路径时，使用现有 `deliverables/dashboards/01_latest` 目录下的 `ABS综合看板_YYYYMMDD.html`。输出必须是现有目录下的本地 HTML；拒绝 URL、目录、输出文件符号链接和指向源台账的硬链接。正式生成允许替换已有 HTML，预览开关仍要求新的本地 HTML 且禁止 `01_latest`。

全年源表的 prepare gate 在最近项目和其它面板计算之前执行。源表 FAIL、HTML FAIL 和全量来源证明不匹配均阻断替换。正式生成使用同目录唯一临时文件，通过全部门禁后原子替换输出；已有相邻 `.qc-tmp` 文件不会被截断。R 列辅助公式缺失缓存沿用已有 WARN，项目配售超限等 FAIL 继续阻断。

主代理已确认完成东道19-3华兴金额修正（0.35 → 0.05，总表 V360 / 白条 U127），并确认 `verify_source` PASS、无 FAIL；正式产物仍须通过生成器的全部门禁。R 公式后续另修。生成前须完成所有 PRODUCERS 中的代码修改；全量来源证明实时计算这些文件的哈希，生成后再次改动生产代码会使原产物校验失败，需要重新生成。

部署由主代理在正式生成成功后使用现有部署入口的 `--skip-generate`，沿用已有其它模块源参数。未来每次 refresh 的完整生成命令都必须继续传入 `--monthly-bookkeeping-release` 才会包含月表；本次保留旧默认行为，未添加该参数的旧生成命令仍只生成原簿记面板。不能用旧的局部簿记刷新替代月表完整生成。

此改动只提供正式产物生成能力，不执行提交、推送或部署。
