# 风险表现定稿与上线

入口：资产大盘 > 发行统计 / 消金资产 / 风险表现，原两个正式面板继续保留。
风险表现下分动态池、静态池，共用资产筛选；两种口径独立保存披露时点，不强行对齐。

来源：2026-11-05通过JoySpace专用Sheets工具读取的本地快照。
动态池：“动态池数据（可对外披露）”首表，2023-06至2026-06，共9时点。顶部仅显示核销后逾期率、不良率，变化以百分点显示；余额保留在趋势图及时间列浮层中，金额显示整数。
静态池：“静态池逾期率&不良率”右侧对外披露表，2023-12至2025-12，共5时点。指标为逾期率、不良率、年化不良率，一行三列。
静态池指标下显示与上一披露时点同名资产的百分点差；不显示“较前期”，无同名前期则留空。观察账龄和均值范围变化说明继续保留，不将变化视为恒定口径同比。
2025-12取现标注不披露，不包含其数据；仅显示现金贷整体，不与早期取现拼接。

白条筛选对应动态池白条及静态池赊销白条/信托白条，不合并静态指标；现金贷和白条取现分别按原披露系列筛选。
时间列悬浮显示该时点全部披露资产全部指标，不退化为单点信息。横轴保留全部时点季度和年份。
原独立动态池、静态池Demo保持原样，未删除或覆盖，整合Demo也继续保留。
