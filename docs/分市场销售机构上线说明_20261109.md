# 分市场销售机构统计

原机构统计中的销售表替换为交易所、银行间两表，桌面并排、手机分市场选择；管理人、托管行表保留。交易所只含上交所、深交所，沿用券商筛选；银行间含银行及券商。中保登、非标等不计入两表。

参与规模为参与项目全额，联席项目计入各家；占比以对应市场的去重项目规模为分母。投行认购按所属市场中标份额统计，不混用其他市场，不把银行普通认购计入投行列。

建行和建设银行统一为建设银行，在项目展开之前归并，同一项目两个名称只计一次。别名仅用于本分市场销售统计，源台账及其他角色不改写。

1106定稿台账统计：交易所94个项目、912.11亿元、19家机构；银行间42个项目、416亿元、20家机构。建设银行13个项目、128.90亿元、30.99%。原Demo保留。

验证：全量原有351项测试通过，新增别名与市场中标份额测试通过。综合看板16面板结构通过。桌面及手机版核验两市场机构行数、建设银行合并值、表格和导航。发布包须解密比对，公网逐文件核验。
