# 次级速查月度更新流程

每月从 JoySpace《终版-26年次级分配》读取所有月份工作表，保存为 `N月.tsv` 到同一导入目录。导入脚本会自动发现目录中的月份，不再使用固定的1—10月清单。

## 导入前检查

先运行只读检查：

```bash
PYTHONPATH=scripts .venv/bin/python scripts/lab/secondary_allocation_quick.py \
  --check-source-dir <月份TSV目录>
```

如果源目录出现快照尚未导入的新月份，检查会返回非零状态，并列出缺失月份。确认后再执行导入：

```bash
PYTHONPATH=scripts .venv/bin/python scripts/lab/secondary_allocation_quick.py \
  --import-dir <月份TSV目录> --snapshot-date <日期>
```

导入脚本会校验月份连续、表头可识别，并拒绝覆盖为空快照。导入后更新综合看板。
