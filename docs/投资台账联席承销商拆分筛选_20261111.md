# 投资台账联席承销商拆分筛选

问题：台账“联席承销商”字段是“甲/乙/丙”的组合文本，原筛选选项按整段组合生成，只能选“江苏银行/南京银行/宁波银行”这类组合，无法单独查询宁波银行。

修复：筛选选项和计数改为按“/”拆成单一机构；同一项目出现多家机构时，每家都计入参与记录数。筛选时按“该机构是否参与该项目”匹配，字段内多选仍为“或”，跨字段仍为“且”。表格和导出保留台账原始组合文字，便于核对。

兼容：智能问答或旧筛选条件若传入组合文本，会先拆成单一机构再匹配。空值、横杠和“无”不作为机构选项。

验证：2026年选项由组合文本变为33家单一机构，选择宁波银行筛出11条；2025年由69段组合变为31家，选择宁波银行筛出271条；多选宁波银行或南京银行返回并集；组合文本不再出现在下拉选项。新增回归测试覆盖单机构选项、单机构筛选、多选并集、旧组合条件兼容。
