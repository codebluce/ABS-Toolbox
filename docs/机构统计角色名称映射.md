# 机构统计角色名称映射

本规则按用户确认的报表统计口径执行，不用于判断法律主体相同。

| 表格 | 原始名称 | 统计名称 |
| --- | --- | --- |
| 管理人统计 | 国证资管 | 国投证券 |
| 管理人统计 | 天风证券 | 天风资管 |
| 管理人统计 | 华泰证券 | 华泰资管 |
| 销售机构统计 | 建投 | 中信建投 |

执行清单位于 `data/institution_stats_role_aliases.json`。管理项目数、管理规模、销售项目数、参与规模和投行实际认购规模，分别按对应表的标准名称聚合。同项目销售机构重复写法在归并后只计一次参与规模。管理人规则不应用于销售机构，销售规则不应用于管理人；认购机构筛选与原始发行台账保持原口径。

同业发行信托全称的统计归并规则另见《同业发行信托名称映射.md》，不改变原始来源名称。
