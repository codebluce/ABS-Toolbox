# 机构统计·管理人表投行认购按角色拆分（2026-11-18）

## 变更

机构画像 > 机构统计 > 管理人统计表，原「投行认购规模(亿)」单列拆为三列：

| 列 | 含义 |
|---|---|
| 管理人 | 该机构作为**计划管理人**的项目中，其投行中标份额（V列认购份额） |
| 销售机构 | 该机构作为**联席承销商**的项目中，其投行中标份额；交易所、银行间均计入 |
| 合计 | 前两列之和 |

表头采用两行分组结构：「投行认购规模(亿)」下分管理人 / 销售机构 / 合计。

## 口径

- 以每条 U 列含「投行」的中标记录为单位，按该机构在对应项目中的角色归属。
- 第三方投行认购（既不是该项目管理人、也不是联席承销商）不计入任何角色列，因此合计可能小于该机构全部投行中标额。
- 同一项目同时具备两种角色时优先计入管理人角色，避免合计重复计算（当前数据无此情形）。
- 管理人角色按 manager 角色别名归并，销售机构角色按 sales 角色别名 + 销售表展示名归并。
- 两个角色列先按 2 位小数取整，合计由取整后的两列相加，保证页面三列能对上。
