# 机构统计·投行认购认定与角色拆分（2026-11-18）

## 认定规则（用户确认）

一条认购记录是否算“投行认购”，按以下判断，命中任一即计入：

1. **认购机构标注“投行”或“自营”** → 明确投行资金（券商投行条线 / 自营盘），不论该机构在该项目中是否担任管理人/销售机构。
2. **未标注上述字样，但该机构在项目中有角色**：
   - 是该项目**计划管理人** → 计入“管理人”列；
   - 是该项目**联席承销商**（交易所、银行间都算）→ 计入“销售机构”列。
3. **标注“客需”** → 客户需求资金，不认定为投行资金（例：国泰海通客需）。
4. 既无标注、又无角色 → 不认定为投行资金（如理财子公司、纯财务投资人）。

归属优先级：管理人角色优先于销售机构角色，避免同一笔重复计算。
有明确投行标识但既非该项目管理人也非联席承销商的，计入**跨期**列。

## 管理人表结构（8 列）

| 列 | 含义 |
|---|---|
| 管理人 | 该机构作为计划管理人的项目中标份额 |
| 销售机构 | 该机构作为联席承销商的项目中标份额（含交易所、银行间） |
| 跨期 | 有明确投行标识、但无管理人/销售机构角色的认购 |
| 合计 | 管理人 + 销售机构 + 跨期 |

表头两行分组：「投行认购规模(亿)」下分管理人 / 销售机构 / 跨期 / 合计。

## 销售机构表结构（6 列）

| 列 | 含义 |
|---|---|
| 投行认购 | 该机构作为联席承销商的项目中标份额（与管理人表“销售机构”列同口径） |
| 跨期 | 该市场内、有明确投行标识但无角色的认购 |

对同时出现在管理人表的机构：交易所“投行认购” + 银行间“投行认购” = 管理人表“销售机构”列（逐家一致）。
