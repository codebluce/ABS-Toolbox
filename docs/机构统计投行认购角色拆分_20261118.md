# 机构统计·投行认购认定与角色拆分（2026-11-19 定稿）

## 认定规则（用户确认）

一条认购记录是否算“投行认购”：

0. **认购机构含“自营”或“客需”** → 整条排除，不论该机构在该项目中是否担任管理人/销售机构。
1. **标注“投行”** → 明确投行资金，不论角色。
2. **未标注“投行”，但该机构在项目中有角色**：
   - 是该项目**计划管理人** → 计入“管理人”列；
   - 是该项目**联席承销商**（交易所、银行间都算）→ 计入“销售机构”列。
3. 无标注且无角色 → 不认定为投行资金。

归属优先级：管理人角色优先于销售机构角色，避免同一笔重复计算。
标注“投行”但既非该项目管理人也非联席承销商的，计入**跨期**列。

## 管理人表结构（8 列）

| 列 | 含义 |
|---|---|
| 管理人 | 该机构作为计划管理人的项目中标份额 |
| 销售机构 | 该机构作为联席承销商的项目中标份额（含交易所、银行间） |
| 跨期 | 标注“投行”但无管理人/销售机构角色的认购 |
| 合计 | 管理人 + 销售机构 + 跨期 |

表头两行分组：「投行认购规模(亿)」下分管理人 / 销售机构 / 跨期 / 合计。

## 销售机构表结构（5 列，未改动）

投行认购只统计销售机构角色，与管理人表“销售机构”列同口径：
对同时出现在管理人表的机构，交易所表 + 银行间表 = 该列（逐家一致）。
