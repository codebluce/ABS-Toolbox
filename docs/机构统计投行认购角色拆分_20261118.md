# 机构统计·投行认购认定与角色拆分（2026-11-18）

## 认定规则（用户确认）

一条认购记录是否算“投行认购”，按以下两条并列判断，命中任一即计入：

1. **认购机构标注“投行”** → 明确投行资金，不论该机构在该项目中是否担任管理人/销售机构。
2. **未标注“投行”，但该机构在项目中有角色**：
   - 是该项目**计划管理人** → 计入“管理人”列；
   - 是该项目**联席承销商**（交易所、银行间都算）→ 计入“销售机构”列。
3. 既未标注“投行”、又无上述角色 → 不认定为投行资金（如理财子公司、纯财务投资人）。

归属优先级：管理人角色优先于销售机构角色，避免同一笔重复计算。
仅标注“投行”但既非该项目管理人也非联席承销商的，计入**合计**但不进前两列（第三方投行认购）。

## 管理人表结构

| 列 | 含义 |
|---|---|
| 管理人 | 该机构作为计划管理人的项目中标份额（含未标注“投行”的跟投） |
| 销售机构 | 该机构作为联席承销商的项目中标份额（含未标注“投行”的认购） |
| 合计 | 管理人 + 销售机构 + 第三方投行认购 |

表头两行分组：「投行认购规模(亿)」下分管理人 / 销售机构 / 合计。

## 销售机构表口径

销售表的“投行认购规模”只统计**销售机构角色**，与管理人表“销售机构”列同口径：

- 对同时出现在管理人表的机构：交易所表 + 银行间表 = 管理人表“销售机构”列（逐家一致）。
- 销售表另含只在销售角色出现、不在管理人表的机构（含银行间承销银行），故两表合计大于该列合计。
