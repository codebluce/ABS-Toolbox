# 发行统计上线说明（2026-11-05）

## 入口及界面

综合看板「资产大盘 > 发行统计」，桌面与手机均提供「消金资产 / 发行统计」子标签。
统计页保留2025全年、2026累计及两年对比。三张卡片依次展示渠道总览、大类累计规模、原始资产分类的全量渠道图。
原始资产图覆盖2025年21类、2026年15类，单图显示各渠道金额与该资产内占比；保留搜索、渠道排序、点击项目及紧凑行距。
两年对比除渠道外，同时比较8个资产大类的规模、占比和期数。2025融资租赁与2026汽车融资租赁按各自名称并排显示。

## 统计口径

使用2025年源台账总表、2026年10月30日定稿总表，按同年「序号 + 项目名称」识别一期。
相同项目的资产、渠道、簿记日和规模须一致，投资人或分层明细不重复累加。含自持及各层级、续发规模，统计累计发行量，非存续余额。
上交所/深交所归交易所；银行间独立；平层非标/结构化非标/非标归非标；中保登归保登，互不重复。
混池按整期归现金贷，不重复计入白条。原资产名称和源表行号保留用于回查。

## 实现及验证

生产入口 scripts/asset_issuance_panel.py、asset_issuance_panel.html；生成器全量生成时读取两年台账，失败阻断输出。
通过隔离离线组件复用已确认界面，避免其样式和脚本影响其他面板。手机直接复用桌面组件，校验两端内容一致。
来源门禁同时检查2025和2026源表哈希以及生产模板版本；当前受控生产输出不再读取Demo产物。

已运行统一测试290项全部通过；15面板结构门禁通过；真实浏览器完成桌面1440×1050、手机390×844入口和交互验收。

## 同比补充

两年对比保留2025全年与2026累计展示，新增2025同期规模及2026同期同比。同期截止日由2026最新簿记日自动确定，目前2026-01-01至2026-10-29，对比2025-01-01至2025-10-29。
渠道总规模及8个资产大类均展示同比：(本期/去年同期-1)×100%。去年同期为0、本期有发行显示“新增（同期为0）”；两期均0显示“—”，不生成无限百分比。
租赁按用户确认的2025融资租赁与2026汽车融资租赁进行类别对比，保留各年名称。
